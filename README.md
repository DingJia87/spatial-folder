# 空间文件夹 Spatial Folder

一款面向“空间记忆型用户”的原生 macOS 文件画布。

选择一个真实文件夹后，App 会把它的第一级文件和子文件夹呈现在类似 macOS 桌面的画布上。你可以按自己的空间习惯自由摆放；再次打开时，所有图标仍停留在原来的位置。

> 当前版本：**v2.1.1 轻度使用测试版**
>
> 适合个人与小范围朋友试用；重要文件仍建议保持正常备份。

## 下载和安装

在 GitHub 右侧的 **Releases** 中下载 `Spatial-Folder-v2.1.1-macOS-arm64.zip`：

1. 解压 ZIP，把 `空间文件夹 2.1.1.app` 拖入“应用程序”。
2. 第一次启动时，右键 App，选择“打开”。
3. 如果 macOS 仍然阻止启动，在“系统设置 → 隐私与安全性”中确认打开。
4. 选择一个文件夹，即可建立它自己的空间画布。

系统要求：macOS 14 Sonoma 或更高版本、Apple Silicon Mac。

## 它适合什么场景

- 不想把文件堆在系统桌面上，但需要依靠位置记忆文件。
- 希望把项目资料按“左上待处理、中央进行中、右侧归档”等空间区域组织。
- 不想改变真实文件结构，也不想创建一堆替身链接。
- 在外接显示器和 Mac 内置屏幕之间切换工作。

## 主要功能

### 稳定的空间画布

- 一个真实文件夹对应一张独立画布，只展示该文件夹的第一级内容。
- 自由拖动、网格吸附、框选、多选和多文件拖动。
- 保存每个图标的位置、图标大小和文字大小。
- 8×8 主画布最多容纳 64 项；更多项目进入“待放置区”，不会打乱已有布局。
- 新出现的文件优先进入空闲位置，已有文件不会自动重排。
- 支持锁定布局、撤销、重做、布局备份、导入和导出。

### 跨显示器稳定性

- 每个文件夹保存固定的逻辑画布。
- 从外接显示器切换到 Mac 内置屏幕后，只缩放视图，不改写文件坐标。
- 图标、字体、间距和壁纸使用同一比例缩放，避免小屏幕上挤成一团。
- 如旧版布局已经被压缩，可在大屏幕上使用“布局 → 将当前显示器设为基准画布”。

### 真实文件操作

- 双击文件：用 macOS 默认应用打开。
- 双击文件夹：在 Finder 中打开。
- 支持重命名、复制、剪切、粘贴、制作副本、压缩和分享。
- 支持 Finder 原生颜色标签、显示简介和“在 Finder 中显示”。
- 删除会把真实文件移入 macOS 废纸篓，并非只隐藏画布入口。
- 可从 Finder 把文件拖入画布，也可把文件拖到其他应用。
- 可静默新建文件夹、Excel 工作簿、Word 文档和 PowerPoint 演示文稿。

### 外观和长期使用

- 默认使用当前显示器的系统桌面壁纸，也可选择自定义图片。
- 支持跟随系统、浅色和深色外观。
- 自动恢复上次打开的文件夹。
- Finder 中重命名文件后保留原位置。
- 原文件夹被移动时尝试自动恢复，也支持手动重新关联。
- 文件夹变化采用防抖刷新和图标缓存，降低持续使用时的资源消耗。

## 安全边界

- 画布展示的都是真实文件，不是链接或副本。
- 在画布中拖动图标只改变布局，不会移动真实文件。
- 重命名、复制、粘贴和移至废纸篓会真实作用于文件系统。
- 布局元数据保存在 `Application Support/SpatialFolder/Layouts`，与用户文件分开。
- App 不上传文件，当前版本不包含账户、云同步或遥测服务。

## 当前限制

- 只展示所选文件夹的第一级内容，不递归展示子文件夹。
- 文件夹会在 Finder 中打开，不会进入下一层画布。
- 第三方 Finder 扩展的右键菜单无法保证迁移；可使用“在 Finder 中显示”。
- 当前安装包使用本地签名，尚未进行 Apple Developer ID 公证。
- 不要同时运行旧版 2.1 和 2.1.1；两者会读取同一份布局数据。
- 尚未专门处理 iCloud 多设备同时修改布局时的冲突。

## 反馈建议

这是轻度使用测试版。反馈问题时，建议附上：

- macOS 版本和 Mac 型号；
- 是否连接外接显示器及两块屏幕的分辨率；
- 文件数量和复现步骤；
- 问题发生前最后一次操作。

请勿在反馈中上传包含隐私内容的真实文件。
