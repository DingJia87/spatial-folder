# 空间文件夹

一个轻量的原生 macOS 文件夹画布：把真实文件夹的第一层内容，按你自己熟悉的位置呈现出来。

它面向依靠空间记忆工作的人：你记得“文件在画面右上角”，而不仅是它的名字或所在层级。

> 这不是 Finder 的替代品。Finder 仍负责真实文件与系统集成；空间文件夹只保存一份独立的画布布局。

## 当前版本：v2.0.0

## 它解决什么问题

- 桌面放文件会变乱，但用 Finder 列表又失去位置感。
- 项目里的资料、数据、输出物需要按“空间分区”组织，而不是不断新建子文件夹。
- 文件应继续是原来的真实文件，能被 Excel、Word、邮件和 Finder 正常使用。

选择一个文件夹后，App 只展示它的第一层内容。每个文件夹都有自己的画布；你拖动图标后，位置会被保存，下一次打开保持不变。

## 主要功能

### 空间画布

- 图标化画布、网格吸附、框选、多选与多文件拖动。
- 记住每个文件和文件夹的图标位置、大小与文字大小。
- 支持系统桌面壁纸或自定义壁纸，以及跟随系统/浅色/深色外观。
- 新出现的项目进入固定的右上“收件区”，不会打乱你已经摆好的图标。
- 最近空间入口与画布内筛选，切换和查找都不改变布局。

### 真实文件操作

- 双击文件：用 macOS 默认应用打开；双击文件夹：在 Finder 打开。
- 重命名、移至废纸篓、制作副本、压缩、分享、显示简介、在 Finder 中显示。
- 支持 Finder 原生颜色标签，并在画布上显示颜色点。
- 右键新建文件夹，以及可静默创建 Excel、Word、PowerPoint 空白文件。
- 支持从 Finder 把文件拖入画布；画布内支持复制、剪切、粘贴。

### 轻量与安全边界

- 文件系统始终是真实来源；画布只存储布局元数据，不创建替身或重复文件。
- 拖动画布内图标只改位置，不移动真实文件。
- 删除操作使用 macOS 废纸篓，不会只删除一个画布入口。
- 文件夹变动采用防抖刷新与图标缓存，适合持续使用。

## 使用方式

1. 打开 App，选择一个本地文件夹。
2. 将其中的文件和子文件夹拖到你习惯的位置。
3. 之后直接打开 App，它会恢复上次的文件夹和布局。
4. 用右键菜单进行新建、标签、压缩、分享和删除等操作。

布局数据保存在 macOS 的 Application Support 中，与用户文件分离。

## 开发运行

```zsh
swift build
./.build/arm64-apple-macosx/debug/SpatialFolder
```

运行 `./scripts/package_app.zsh` 会生成 `Release/空间文件夹 2.0.app` 及压缩包；发布文件不提交到 Git。

## 系统要求

- macOS 14 Sonoma 或更高版本
- Apple Silicon 构建产物
