# 空间文件夹 Spatial Folder

一款面向“空间记忆型用户”的原生 macOS 文件画布。

选择一个真实文件夹后，App 会把它的第一级文件和子文件夹呈现在类似 macOS 桌面的画布上。你可以按自己的空间习惯自由摆放；再次打开时，所有图标仍停留在原来的位置。

> 当前正式版本：**v4.3.0 收纳确认版**
>
> 以4.2为基线，仅增加收纳前确认；重要文件仍应保持正常备份。

## 下载和安装

本地正式App和ZIP位于`Release/4.3.0/`；GitHub Releases将在本地正式版提交并推送后更新。

1. 解压后，把 `空间文件夹.app` 拖入“应用程序”。
2. 第一次启动时，右键 App，选择“打开”。
3. 如 macOS 仍阻止启动，在“系统设置 → 隐私与安全性”中确认打开。
4. 选择一个文件夹，即可建立它自己的空间画布。

系统要求：macOS 14 Sonoma 或更高版本、Apple Silicon Mac。

## 核心能力

### 稳定的空间画布

- 一个真实文件夹对应一张独立画布，只展示该文件夹的第一级内容。
- 支持自由拖动、网格吸附、双向框选、多选和整组拖动。
- 保存每个图标的位置、图标大小和文字大小。
- 8×8 主画布最多容纳 64 项；更多项目进入可搜索、可多选的待放置区。
- 新出现的文件进入可预测空位，不会自动重排已有文件。
- 支持布局锁定、撤销、重做、备份、导入和导出。

### 真实文件操作

- 双击文件：用 macOS 默认应用打开；双击文件夹：在 Finder 中打开。
- 支持重命名、复制、剪切、粘贴、制作副本、压缩、分享和显示简介。
- 支持 Finder 原生颜色标签和“在 Finder 中显示”。
- 删除会把真实文件移入 macOS 废纸篓，并非只隐藏画布入口。
- 可从 Finder 把多个文件一次拖入画布，也可把画布文件拖到其他应用。
- 从 Finder 拖入时，新图标从鼠标投放点附近按网格落位；已有图标不会被重排。
- 可静默新建文件夹、Excel 工作簿、Word 文档和 PowerPoint 演示文稿。

### 2.4 批量交互

- 一次拖入多个文件只生成一个批次、一个进度任务和一次冲突选择。
- 右键已框选项目时，复制、剪切、副本、压缩、分享、标签、大小、待放置区和废纸篓作用于整个选择集合。
- 多选拖动使用统一网格位移，靠近边界时保持组内相对位置。
- 待放置区支持独立搜索、全选当前结果和批量放回主画布。

### 文件安全和高强度使用

- 同一张画布只能由一个 App 进程写入；第二个会话显示只读，避免同时写坏数据。
- 长耗时复制、移动、压缩、废纸篓和撤销/重做在后台串行执行，并显示进度。
- 每完成一个真实文件步骤就立即保存事务记录；中途失败会回滚已完成内容，无法确认时明确进入“需核对”。
- 同名冲突不会静默覆盖，必须选择“保留两者”、“替换”或“取消”。
- 文件操作撤销记录跨 App 重启保留；替换操作也可完整恢复。
- 可导出不包含文件名、文件夹名或完整路径的诊断 JSON。

### 2.5 恢复与性能

- 操作历史改为“原子快照 + JSONL 增量日志”；每个文件步骤只追加事件，达到阈值后自动压缩。
- 2.4 的操作历史首次打开时自动迁移，旧文件会保留为归档副本。
- 日志写入、标签、创建、重命名、模板复制和文件属性读取均移到后台串行执行。
- 新增异常恢复向导：崩溃或强制退出后，依据真实磁盘状态逐项展示证据；证据不足时绝不自动猜测。
- 布局、日志、文件访问和恢复分析已从主模型拆分为可独立测试的模块。

### 2.6 标签筛选与操作安全

- 顶部搜索框旁可按 Finder 原生红、橙、黄、绿、蓝、紫、灰标签颜色或“无标签”筛选。
- 多种颜色之间按任一匹配，搜索与颜色筛选同时生效；切换空间时自动清空筛选。
- 标签颜色按 Finder 原生编号识别，自定义标签名称和不同系统语言不会改变实际颜色。
- 筛选隐藏的项目会立即退出选择集合，批量菜单和快捷键不会操作用户当前看不见的文件。
- 没有匹配项目时显示明确空状态，并可一键清除筛选。
- 顶部筛选只作用于主画布；待放置区保持完整并继续使用自己的独立搜索。

### 3.0 工具栏与外观体验

- “选择文件夹”、当前空间名称和最近空间统一为一个“当前空间”菜单。
- 顶部只常驻空间入口、搜索、标签筛选、刷新和“更多”，异常、恢复及待放置状态按需出现。
- 壁纸、外观、锁定、最近操作和布局维护按用途收进“更多”菜单，降低顶部视觉噪声。
- 锁定布局只保护图标位置，不再错误阻止自定义壁纸或系统桌面壁纸切换。
- 重复选择当前壁纸不会制造无意义的撤销记录。

### 4.0 一键收纳桌面

- 顶部“收纳桌面”按钮或 `⇧⌘D` 可把桌面第一级可见文件和文件夹整体移动到当前空间。
- 文件夹内部内容保持原样；同名项目自动保留两者，不覆盖目标中的原文件。
- 新图标叠放在画布右侧中下部并显示数量；逐个拖走顶层项目即可自行摆放。
- 收纳点被旧图标占用时整堆寻找附近空位，已有图标不移动，空间不足时进入待放置区。
- 隐藏项目、未完成下载以及会包含当前目标空间的桌面项目自动排除。
- 整批移动进入最近操作记录，可以一次撤销回桌面。

### 4.1 全局快捷唤醒

- 默认按 `⌃⌥空格`：App 不在前台时显示并置顶，已经在最前时再次按下即可隐藏。
- 可在“更多 → 全局快捷键设置”中录制自定义组合键、停用功能或恢复默认。
- 新组合键如被 macOS 或其他 App 占用，会明确提示并保留原来可用的快捷键。
- 菜单栏常驻“空间文件夹”入口，可显示/隐藏主窗口、收纳桌面、切换最近空间或退出。
- 使用系统热键注册，不要求辅助功能或输入监控权限。
- 主窗口改为单实例；关闭后仍可从快捷键或菜单栏重新唤回，不会重复创建画布窗口。
- 在 Finder 等外部位置修改标签后，画布会自动同步；文件夹图标本体会按 Finder 标签着色，文件仍保留原图标并显示颜色点。

### 4.2 标签同步稳定性

- Finder 或 App 内修改标签后，画布约一秒内同步，不需要重启或重新选择文件夹。
- 文件夹图标本体按首个 Finder 颜色标签着色；普通文件保留系统图标并显示标签点。
- 清除标签后再选择新颜色，只写入当前选择，不会把旧标签从视图缓存带回。
- 顶部筛选与右键标签菜单统一显示原色圆点和文字；选中颜色显示同色勾选圆点。
- 普通64项画布的标签核对约占单核0.05%；筛选状态下超大目录使用五秒全量兜底，避免持续高频扫描。

### 4.3 收纳前确认

- 点击顶部按钮、菜单栏入口或`⇧⌘D`后，先只读统计桌面项目。
- 确认卡片显示总数、文件数、文件夹数和目标空间。
- 点击“取消”或关闭卡片不会移动任何真实文件；只有点击“收纳”才执行原有可撤销批量移动。
- 本版本不改变标签筛选、文件名显示、布局格式或其他4.2交互。

### 性能、显示器与外观

- 文件夹扫描、壁纸解码和长文件操作不在主线程执行。
- 图标按可见需要加载并设置缓存上限；3,000 项目录有性能回归测试。
- 每个文件夹使用固定逻辑画布，跨显示器只缩放视图，不改写图标坐标。
- 普通窗口保持画布比例；最大化和全屏使用完整可见区域，背景连续覆盖到底部。
- 默认跟随当前显示器系统壁纸，也可选择自定义壁纸。
- 支持跟随系统、浅色和深色外观。
- 自动恢复上次文件夹；Finder 外部重命名和根文件夹移动会尽量保留布局。

## 安全边界

- 画布展示的都是真实文件，不是链接或显示副本。
- 在画布中拖动图标只改变布局，不会移动真实文件。
- 重命名、复制、粘贴、标签和废纸篓会真实作用于文件系统。
- 布局元数据保存在 `Application Support/SpatialFolder/Layouts`。
- 可逆文件操作记录保存在 `Application Support/SpatialFolder/Operations`。
- App 不上传文件，当前版本不包含账户、云同步或遥测服务。

## 当前限制

- 只展示所选文件夹的第一级内容；文件夹会在 Finder 打开，不进入递归子画布。
- 第三方 Finder 扩展的右键菜单无法保证迁移，可使用“在 Finder 中显示”。
- 当前安装包使用本地临时签名，尚未进行 Apple Developer ID 公证。
- 布局撤销快照只在当前 App 进程内有效；真实文件操作记录可跨重启。
- 如果文件在操作后又被其他 App 移动或删除，撤销会停止并提示核对，不会猜测新位置。
- 尚未处理 iCloud 多设备同时修改同一画布的冲突。
- 旧测试版不认识 2.5 起使用的会话锁和增量日志，不要同时使用旧版与 2.5 及更高版本编辑同一个真实文件夹。

## 项目结构

- `Sources/SpatialFolder`：生产代码和内置 Office 空白模板。
- `Tests`：标准测试、完整自测和性能基线入口。
- `scripts`：开发启动、测试、性能和打包脚本。
- `config`：发布环境配置。
- `Assets`：App 图标与打包元数据。
- `docs`：按计划、发布、维护、性能和技术资料分类的版本文档。
- `Release`：本地构建产物与历史压缩包，不纳入 Git；对外发布以 GitHub Releases 为准。

反馈问题时请附上 macOS 版本、Mac 型号、显示器分辨率、文件数量和可重复步骤。请勿上传包含隐私内容的真实文件；优先使用 App 导出的诊断 JSON。
