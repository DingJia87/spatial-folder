# 支持与反馈

## 报告问题

请通过 [GitHub Issues](https://github.com/DingJia87/spatial-folder/issues) 提交可复现问题，并尽量包含：

- macOS 版本和 Mac 型号；
- 指针空间版本；
- 显示器分辨率及缩放设置；
- 当前文件夹的大致项目数量；
- 复现步骤、预期结果和实际结果。

不要上传包含私人文件名、完整路径或文件内容的截图与日志。需要诊断时，优先使用 App 的“导出诊断信息”。

## 功能建议

建议应说明它如何帮助用户更快地依靠空间定位文件。项目优先保持轻量、低后台占用和真实文件安全，不以替代 Finder 为目标。

## 安全问题

涉及文件丢失风险、权限绕过或敏感信息泄露的问题，请按照根目录 [安全政策](../SECURITY.md) 私下报告，不要先公开完整细节。
