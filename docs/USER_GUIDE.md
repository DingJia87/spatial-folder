# 指针空间用户指南

## 建立空间

首次打开后选择一个真实文件夹。指针空间只显示它的第一级文件和子文件夹，并为该文件夹保存一张独立画布。切换到其他文件夹不会改变原画布的位置。

## 切换常用空间

主窗口顶部按打开顺序保留最多 5 个空间快捷入口，当前空间只会高亮，点击切换不会改变任何入口的位置。名称过长时把鼠标移上去可以查看完整路径。

前 5 个新打开空间会依次占据顶部位置。再打开新的第 6 个空间时，App 会要求选择替换哪一个位置；确认前不会切换当前画布，确认后只有所选位置发生替换。按住入口右侧的三横线手柄拖到另一个空间，可以让源空间占据目标位置；右键非当前入口可以从顶部移除。窄窗口暂时放不下的入口和最近空间位于末尾的“更多空间”菜单。未激活空间只保存入口，不会扫描文件、监听变化或加载图标。

## 快速唤醒

默认按 `⌃⌥空格`显示指针空间；主窗口已经在最前时再次按下即可隐藏。可以在“更多 → 全局快捷键设置”中录制其他组合键，也可以从菜单栏图标进入。

## 摆放和查找

- 拖动图标会吸附到网格，只改变画布位置，不移动磁盘文件。
- 搜索框匹配文件名和 Finder 标签名称。
- 标签菜单支持红、橙、黄、绿、蓝、紫、灰和无标签筛选。
- 新项目进入可预测空位；主画布满后进入待放置区。
- 布局可以锁定、备份、导入、导出或找回越界项目。
- 顶部撤销和重做按钮可连续后退或前进多步；鼠标悬停会说明下一项操作。刷新按钮仅用于 Finder 外部变化没有及时显示时手动重新扫描。
- 每个空间单独保留最近 3 步布局撤销和重做。切换到其他空间或退出 App 不会清除；重新回来后继续操作该空间自己的历史。真实文件操作继续使用独立事务记录和执行前安全核对。

## 布局历史

在“更多 → 布局维护 → 布局历史”中，可以按时间查看自动备份和手动快照。选择一份备份后，界面会并排显示当前布局与备份布局，并列出将调整、新增保留和已不存在的项目数量。

布局历史右上角的“更多”提供“导出当前布局文件”“从布局文件导入”和“在访达中显示备份”。这些是迁移与长期备份工具，日常使用通常只需要快照和恢复。

“恢复布局”只恢复图标位置、大小、待放置状态和基准画布，不恢复文件。备份里记录的文件如果已经删除，只会显示提示并忽略旧坐标；备份后新增的文件保持当前位置。默认不会改变当前壁纸和锁定状态。

## 文件操作

双击文件会调用 macOS 默认应用，双击文件夹会在 Finder 中打开。右键菜单提供重命名、复制、剪切、粘贴、副本、压缩、分享、简介、标签和移至废纸篓等操作。

这些命令直接作用于真实文件。涉及覆盖、删除或批量移动时，请阅读确认信息；遇到无法确认的外部变化，App 会停止而不是猜测。

## 收纳桌面

顶部按钮、菜单栏入口或 `⇧⌘D`会先统计桌面第一级可见项目，并显示文件数、文件夹数和目标空间。确认后才会移动；文件夹连同内部内容整体移动，新项目在画布右侧中下部叠放，随后可逐个拖开。

## 升级到 5.0

把旧的“空间文件夹.app”退出并从“应用程序”移除，再复制“指针空间.app”。两个名称使用相同 Bundle ID 和数据目录，不要同时运行。已有布局、最近空间、快捷键和操作历史会继续沿用。

## 备份建议

指针空间包含事务记录和恢复保护，但它不是备份软件。重要文件仍应使用 Time Machine、云盘版本历史或其他独立备份方案。
