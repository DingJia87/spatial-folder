# 空间文件夹 3.0 工具栏与壁纸维护说明

本文是 2.5、2.6 维护说明的增量补充；真实文件事务、恢复、日志和筛选安全规则继续有效。

## 1. 布局锁定与壁纸权限

`canEditLayout` 保护图标位置、排列和画布尺寸等布局写入，因此包含 `!isLocked`。

`canChangeWallpaper` 保护显示偏好写入，不包含 `!isLocked`。它仍要求：

- 已打开真实文件夹；
- 布局数据可用；
- 文件夹可访问；
- 当前会话拥有写锁；
- 操作历史未处于加载状态。

不得再次让 `setWallpaper` 复用 `canEditLayout`。布局锁定的语义是“不要移动我的图标”，不是冻结整个外观。

## 2. 壁纸状态

`wallpaperURL == nil` 表示使用 App 当前所在显示器的系统桌面壁纸；非空 URL 表示自定义图片。设置前统一标准化 URL，相同值直接返回，避免生成无意义的撤销记录。

修改壁纸逻辑时必须保留“锁定状态仍可切换并保存壁纸”自测，至少覆盖自定义壁纸、重新打开、恢复系统壁纸和再次重新打开。

## 3. 工具栏状态优先级

顶部常驻项只承担高频导航和查找：

- 当前空间；
- 搜索；
- Finder 标签筛选；
- 刷新；
- 更多。

操作记录损坏、待恢复和待放置属于会影响安全或当前任务的状态，必须按需直接出现，不得仅隐藏在“更多”菜单中。壁纸、外观、锁定、最近操作与布局维护属于低频命令，可收进分组菜单。

## 4. 发布边界

3.0 正式产物只能写入 `Release/3.0.0/`。冻结的 `Release/2.6.0/` 和历史 2.7 开发候选均不得覆盖。
