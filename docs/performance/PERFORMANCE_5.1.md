# 指针空间 5.1 性能说明

测试日期：2026-08-08。

5.1 的布局历史只在用户打开面板时读取最多 12 个 JSON，并使用 SwiftUI 按坐标即时绘制缩略图；不生成图片缓存，不增加定时器、文件监听或后台常驻任务。关闭面板后不再执行预览工作。

## 自动基线

| 项目 | 5.1 结果 |
| --- | ---: |
| 64 项目录扫描 | 0.00446 秒 |
| 500 项目录扫描 | 0.02356 秒 |
| 3000 项目录扫描 | 0.14313 秒 |
| 1000 次日志追加 | 0.09308 秒 |

结果与 5.0 基线处于同一量级。候选 App 约 5.0 MB，ZIP 约 2.5 MB。
