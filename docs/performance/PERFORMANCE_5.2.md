# 指针空间 5.2 性能说明

测试日期：2026-08-08。

5.2 的固定空间只保存最多 5 个文件夹书签和显示顺序。未激活空间不扫描文件、不建立监听、不核对 Finder 标签，也不保留图标缓存；因此空间数量不会线性增加后台工作量。

每个空间的最近 3 步布局撤销与重做使用独立 JSON 按操作即时写入。未激活空间的历史不驻留内存，切换时只加载目标空间；不增加定时器或后台任务。

## 设计结论

顶部显示 5 个空间只增加少量 SwiftUI 按钮和书签数据。真正与文件数量相关的扫描、文件夹监听和图标加载仍只有一套，属于当前活动空间。

结果与 5.1 基线处于同一量级；3000 项扫描为 0.13951 秒，未观察到多空间入口或独立撤销历史带来的目录扫描回退。
