# 空间文件夹 2.5 性能基线

## 目的

这份基线不用来宣称绝对性能，而是为后续版本提供可重复对照，及时发现文件扫描或日志持久化退化。

## 环境与方法

- 日期：2026-07-16
- 架构：Apple Silicon（`arm64`）
- 最低部署目标：macOS 14.0
- SDK：`/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk`
- 命令：`./scripts/run_performance_baseline.zsh`
- 扫描样本：在隔离的临时目录中生成 64、500 和 3,000 个空文件，仅扫描第一级轻量元数据。
- 日志样本：对同一条记录执行 1,000 次 upsert，触发自动压缩，再重放最终状态。

## 2.5.0 基线结果

| 指标 | 结果 |
|---|---:|
| 64 项扫描 | 0.003329 s |
| 500 项扫描 | 0.018868 s |
| 3,000 项扫描 | 0.115346 s |
| 1,000 次增量 upsert | 0.094460 s |
| 压缩后日志重放 | 0.000088 s |
| 压缩后 JSONL 字节 | 0 B |
| 压缩后快照字节 | 314 B |

## 解读与预算

- 3,000 项扫描的自动回归预算是 10 秒；当前基线远低于预算。
- 1,000 次增量写入的回归预算是 10 秒；当前基线证明没有随记录数量反复全量重写。
- 增量日志达到阈值后被原子快照吸收，因此此次基线中 JSONL 为 0 B。
- 这些是微基准，不等价于包含 Finder 图标、壁纸和 SwiftUI 渲染的端到端启动时间。

## 后续使用

每个性能版本在同一台机器上连续运行 3 次，保留中位数。如 3,000 项扫描或 1,000 次追加较本基线增加 50% 以上，应在发布前说明原因或修复。
