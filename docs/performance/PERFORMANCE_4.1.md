| 场景 | 结果 |
| --- | ---: |
| 64 项扫描 | 0.0046 秒 |
| 500 项扫描 | 0.0253 秒 |
| 3,000 项扫描 | 0.1476 秒 |

4.1 的快捷键、菜单栏与标签监听不进入完整目录扫描或布局保存热路径。FSEvents 不可用时的兜底只读取标签；标签未变化时不发布 UI 状态。
