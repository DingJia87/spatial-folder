# 5.3.0 正式试用版计划与验收

## 目标

将 5.2.1–5.2.2 已验证的真实文件安全闭环和顶部拖动稳定修复整理为 5.3.0 正式试用版。不增加新功能，不改变轻量资源模型。

## 范围

1. 统一所有真实文件写入的当前空间授权上下文。
2. 整批文件操作在修改磁盘前完成全量路径预检。
3. 验证撤销/重做记录及系统废纸篓路径。
4. 覆盖文件修改与日志落盘之间的故障窗口。
5. 顶部空间标签拖动仅刷新单枚标签，并作为完整视觉层移动。
6. 保留 5.2 的五空间上限、固定顺序、独立历史和单活动空间资源模型。

## 验收要求

- 22 项标准测试和 82 项完整自测全部通过。
- 性能与 5.2.2 保持同一量级。
- 严格 Release 构建、App 签名、ZIP 解压后签名和版本号全部通过。
- 无后缀 App/ZIP 仅放入新的 `Release/5.3.0/`，不覆盖任何旧包。
- 已完成用户本地试用确认，冻结现有正式产物，并提交、标记 `v5.3.0` 和推送源码。
