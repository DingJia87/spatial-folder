# 指针空间 5.1 计划与验收

## 目标

让普通用户无需阅读 JSON 就能判断布局备份的时间、原因和空间分布，并在恢复前明确知道哪些布局记录会生效。

## 范围

1. “布局维护”提供统一的“布局历史”入口。
2. 按时间列出最多 12 份备份，显示生成原因、项目数和 App 版本。
3. 同时预览当前布局和备份布局，汇总调整、不变、新增、已不存在项目。
4. 支持恢复任意备份；恢复前自动备份当前布局，并保留会话内撤销能力。
5. 默认只恢复位置、大小、待放置状态和基准画布；壁纸与锁定状态由用户明确选择。
6. 支持保存带备注的手动布局快照，兼容 5.0 及更早的 JSON 备份。

## 文件安全边界

- “恢复布局”只读取和写入布局元数据，不是文件恢复功能。
- 布局记录指向的文件已经不存在时，只提示名称并忽略对应坐标。
- 备份后新增的真实文件保持当前画布位置。
- 不查询废纸篓，不创建替身，不复制、移动、覆盖或删除真实文件。

## 验收标准

- 用户不打开 Finder 或 JSON 即可选择、预览并比较备份。
- 缺失文件在恢复确认前可见，且恢复后仍保持不存在。
- 新增文件在恢复后仍存在且位置不变。
- 恢复前当前布局进入备份；旧 JSON 无元数据时仍能显示并恢复。
- 标准测试、自测、性能基线、Release 构建和签名复验全部通过。
