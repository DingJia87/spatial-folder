# 2.7 工具栏精简计划

状态：开发成果已并入 3.0.0。

## 目标

降低顶部工具栏的视觉噪声，让空间选择、搜索和标签筛选成为明确的主路径，同时不隐藏文件安全与恢复状态。

## 范围

- 将“选择文件夹”、当前文件夹名称和“最近空间”合并为一个空间选择菜单。
- 顶部常驻搜索、标签筛选、刷新，以及有内容时才出现的待恢复和待放置状态。
- 将锁定、壁纸、外观、最近操作和布局维护收进“更多”菜单。
- 锁定后，空间入口使用锁图标，画布继续显示“布局已锁定”提示。
- 操作记录损坏时继续显示独立告警入口，不能被“更多”菜单掩盖。

本轮不修改真实文件操作、布局格式、操作历史格式、标签筛选语义和冻结的 2.6.0 安装包。

## 验证

- 标准 SwiftPM 测试：10/10 通过。
- 完整自测：67/67 通过。
- 严格 Release 构建：通过。
- GUI 检查：空间菜单、标签菜单、“更多”菜单、外观勾选、锁定提示和条件状态均可访问。
- 实际检查中发现 SwiftUI `Menu` 默认伸展占据剩余宽度，已使用内容宽度约束修正。
