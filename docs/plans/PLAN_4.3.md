# 空间文件夹 4.3 开发与验收记录

## 版本范围

4.3以4.2为基线，只增加“收纳桌面”执行前确认，不修改标签筛选、文件名显示、布局格式或其他交互。

## 规则

1. 工具栏、菜单栏和`⇧⌘D`先执行只读统计。
2. 确认卡片显示项目总数、文件数、文件夹数和目标空间。
3. 取消或关闭卡片不得创建操作记录、修改画布或移动真实文件。
4. 只有用户点击“收纳”后，才能进入4.2原有批量事务。
5. 切换空间必须清除尚未执行的确认数据。

## 验收

- 自动测试验证确认前来源文件和文件夹仍存在。
- 确认后保留同名处理、叠放、回滚和整批撤销能力。
- 标准测试、完整自测、严格Release构建、签名和GUI检查全部通过。
- 正式App和ZIP放入`Release/4.3.0/`，不覆盖4.2正式包。

## 验收结果

用户确认候选可用并要求作为4.3正式版。标准测试17/17、完整自测71/71、严格Release构建、签名、ZIP解压复验和GUI取消验证均通过。
