# 5.2.2 写入安全闭环计划与验收

## 目标

在 5.2.1 已保护重命名、复制和移动的基础上，把同一份当前空间授权边界覆盖到所有真实文件写入，并用故障注入验证“文件已改、日志未落盘”的最危险窗口。

## 范围

1. 压缩、废纸篓、新建、标签、复制/移动、撤销/重做都必须显式携带当前空间授权上下文。
2. 批量操作在第一次真实文件修改前预检全部源和目标。
3. 撤销/重做验证动作记录与当前空间的关系，并限定废纸篓路径。
4. 注入文件修改后、日志确认前的中断，验证重启核对证据。
5. 注入可捕获的日志落盘失败，验证已修改文件自动回滚。
6. 不增加功能入口、常驻工作或产品资源模型。

## 验收结果

- 22/22 标准测试、82/82 完整自测通过。
- 所有写入入口越界计划均在零磁盘变更时被拒绝。
- 故障窗口能被 pending 日志与磁盘证据识别；可捕获失败会回滚。
- 性能基线与 5.2.1 保持同一量级，无新增长期监听。
