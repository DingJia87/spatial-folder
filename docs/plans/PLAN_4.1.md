# 空间文件夹 4.1 开发与验收计划

## 目标

用一个随时可达、可逆的入口代替反复点击 Dock：按一次全局快捷键显示空间文件夹，再按一次隐藏；菜单栏提供始终可见的备用入口。

## 范围

- 默认 `⌃⌥空格`，支持录制其他带 Control、Option 或 Command 的组合键，也允许单独使用 F1–F20。
- 冲突时不覆盖原来可用的组合键；支持停用和恢复默认。
- 主窗口只保留一个实例，关闭、最小化或位于其他 App 后方时都能重新唤回。
- 菜单栏提供显示/隐藏、收纳桌面、最近空间、快捷键设置和退出。
- 不使用键盘监听，不请求辅助功能或输入监控权限。
- 外部修改 Finder 标签后自动刷新画布颜色，不依赖重启。

## 验收

- 15/15 标准测试和 71/71 完整自测通过。
- 性能基线、严格 Release 构建、App 签名及 ZIP 解压签名复验通过。
- GUI 覆盖后台唤回、再次隐藏、关闭后重开、菜单栏入口和设置页。
- 正式产物冻结到 `Release/4.1.0/`，不覆盖 4.0.0。
