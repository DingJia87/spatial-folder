# 空间文件夹 3.0 开发与验收计划

## 版本定位

3.0 是“工具栏与外观体验版”。它吸收 2.7 工具栏开发候选，并修复锁定画布时系统桌面壁纸无法生效的问题；不迁移真实文件、画布布局格式或操作历史格式。

## 必须满足的目标

| 编号 | 目标 | 验收证据 |
|---|---|---|
| R1 | 收敛顶部工具栏 | 空间、搜索、标签和刷新保持主路径；低频命令收入分组菜单 |
| R2 | 关键状态不被隐藏 | 操作记录异常、待恢复和待放置入口仍按需直接显示 |
| R3 | 锁定不阻止外观设置 | 锁定时仍可选择图片或恢复当前显示器的系统桌面壁纸 |
| R4 | 文件安全边界不放宽 | 只读、布局损坏、文件夹不可用或历史加载期间仍不能写入壁纸设置 |
| R5 | 壁纸设置可持久化 | 自定义与系统壁纸状态在重新打开空间后保持 |
| R6 | 形成正式 3.0.0 | 标准测试、自测、性能、严格构建、GUI、签名及 ZIP 解压复验通过 |

## 完成定义

R1—R6 均有代码或运行证据，正式产物只写入 `Release/3.0.0/`，不覆盖冻结的 `Release/2.6.0/`。完成提交并创建 `v3.0.0` 本地标签后视为冻结。

## 验收记录

- 代码根因：`setWallpaper` 复用了包含 `!isLocked` 的布局编辑条件，菜单却没有禁用提示，导致锁定时点击后静默无效。
- 修复：新增独立壁纸修改条件；布局锁定不参与外观权限判断。
- 回归：锁定、自定义壁纸、重新打开、恢复系统壁纸和再次重新打开均纳入自测。
- 标准 SwiftPM 测试 10/10、完整自测 68/68 通过。
- 性能基线中 3,000 项扫描为 0.148 秒，1,000 次日志追加为 0.098 秒。
- 隔离 GUI 以“已锁定 + 自定义壁纸”启动；点击系统壁纸后自定义路径从持久化数据中清除，锁定保持，重启后状态仍正确。
- 严格 Release 构建、App 签名、ZIP 压缩、解压和解压后签名复验通过。
