# 空间文件夹 2.6 开发与验收计划

## 版本定位

2.6 是“标签筛选与操作安全版”。以冻结的 2.5.0 为基线，不改变文件系统、布局和事务格式，只收敛顶部工具栏、增加 Finder 标签颜色筛选，并修复筛选后不可见项目仍可能参与批量真实文件操作的风险。

## 必须满足的目标

| 编号 | 目标 | 验收证据 |
|---|---|---|
| R1 | 移除顶部“新建文件夹”按钮 | 工具栏不再显示；画布右键新建、事务和撤销测试继续通过 |
| R2 | 支持 Finder 标签颜色筛选 | 七种颜色和无标签可选；多颜色 OR、与搜索 AND |
| R3 | 自定义标签名仍按真实颜色工作 | 扫描保留 Finder 扩展属性中的颜色编号；编号解析测试通过 |
| R4 | 筛选不修改空间布局 | 过滤切换前后 `positions` 完全一致 |
| R5 | 隐藏选择不能参与批量命令 | 筛选变化后选择集只保留可见项目；上下文命令再次限定可见选择 |
| R6 | 筛选状态不制造“文件消失”错觉 | 无结果提示可清除；切换空间自动清空搜索和标签条件 |
| R7 | 待放置区保持独立可访问 | 顶部筛选只作用于主画布，待放置区仍显示全部项目并使用自己的搜索 |
| R8 | 形成 2.6 开发候选 | 版本、测试、性能、严格构建和开发版 App 一致，用户验证后再正式打包 |

## 组合规则

- 搜索匹配文件名或 Finder 标签名称。
- 同时选中多个颜色时，项目匹配任一颜色即可显示。
- 搜索词与标签条件必须同时满足。
- “无标签”可与颜色共同选择，表示显示无标签项目或任一所选颜色项目。
- 未选择颜色且未选择“无标签”时，不施加标签条件。

## 安全规则

筛选只改变 `displayedItems`，不写布局、不移动文件。`selectedItems` 和右键批量目标必须来自当前可见项目；搜索输入、颜色切换、无标签切换、目录刷新和空间切换后都要重新核对选择集合。

## 完成定义

R1—R8 均有代码或运行证据，标准测试、完整自测、性能基线和严格 Debug/Release 构建通过，开发版完成用户验证后，才生成并冻结 `Release/2.6.0/`。

## 当前实施证据（2026-07-21）

- R1—R7 已实现并由自动测试或 GUI 冒烟验证。
- 标准 SwiftPM 测试 10/10、完整自测 67/67 通过。
- 三次性能基线的 3,000 项扫描中位数为 0.137 秒，较 2.5 增加 19.1%，低于 50% 复核阈值。
- 严格 Debug/Release 构建在警告视为错误下通过。
- 隔离 Bundle ID 开发版确认顶部按钮已移除、标签菜单完整、无结果提示和清除筛选可用。
- R8 已完成：用户验收通过，正式 App/ZIP 已在 `Release/2.6.0/` 完成签名、压缩、解压复验并冻结。
