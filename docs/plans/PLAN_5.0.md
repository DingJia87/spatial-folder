# 指针空间 5.0 计划与验收

## 目标

完成品牌升级并减少窗口不可见时的后台唤醒，不改变真实文件行为、布局格式和用户数据路径。

## 范围

1. 用户可见名称、App 包、ZIP、菜单栏和诊断文件统一为“指针空间”。
2. 版本升级为 5.0.0，构建号 5000。
3. 保持 Bundle ID、Swift 模块和 `Application Support/SpatialFolder` 不变。
4. 窗口隐藏、关闭或最小化时暂停标签轮询；恢复显示时立即补查。
5. 精简 GitHub 主页，补齐用户、隐私、支持、安全和维护文档。

## 不在范围

- 新的文件管理功能、全文索引、自动整理、云同步或遥测。
- 改写 Git 历史或删除历史版本的安全记录。
- Developer ID 签名和公证。

## 验收

- 所有标准测试和完整自测通过。
- 性能基线不退化。
- 正式 App/ZIP 名称正确，内部版本和可执行文件一致。
- 解压后通过严格签名复验。
- 旧版布局、偏好和操作记录无需迁移即可读取。
