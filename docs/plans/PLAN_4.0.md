# 空间文件夹 4.0 开发与验收计划

状态：用户确认方案，正式冻结。

## 版本定位

4.0 是“一键收纳桌面”大版本。它把原先讨论的定时自动移动收敛为用户主动触发的一次批量操作，减少后台权限、误执行和维护成本。

## 用户路径

1. 打开目标空间。
2. 点击顶部“收纳桌面”按钮，或按 `⇧⌘D`。
3. 桌面第一级可见文件和文件夹整体移动到当前空间。
4. 新图标在画布右侧中下部叠放为一摞；已有图标保持原位。
5. 需要时从“最近操作”整批撤销回桌面。

## 安全不变量

- 使用移动而不是复制，桌面不会留下重复副本。
- 文件夹作为整体移动，不递归拆分内部内容。
- 同名冲突固定为“保留两者”，绝不覆盖。
- 隐藏项目和 `.download`、`.crdownload`、`.part`、`.icloud` 未完成项目不移动。
- 如果目标空间位于桌面项目内部，该祖先项目不进入收纳批次，避免把目标移入自身。
- 操作记录损坏、只读会话、目标不可用或已有文件操作时禁止执行。
- 锁定只保护已有布局；允许新项目进入右侧中下部收纳堆。

## 验收标准

- 文件与包含子文件的文件夹可以在一个批次中移动。
- 同名目标自动生成唯一名称，原目标内容保持不变。
- 新项目共用右侧中下部收纳点，显示数量角标，拖走顶层后能逐项露出。
- 收纳点被占用时整堆移动到附近空位，已有位置完全不变。
- 超出容量的项目进入待放置区。
- 整批撤销能恢复桌面文件和文件夹。
- 标准测试、自测、性能、严格构建及隔离 GUI 验证通过。
- 用户确认单点堆叠方案后，生成正式 App/ZIP、提交冻结并创建 `v4.0.0` 标签。
