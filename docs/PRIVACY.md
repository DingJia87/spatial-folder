# 隐私说明

生效日期：2026-08-01

指针空间的设计原则是让文件留在用户的 Mac 上。

## 数据处理

- 不要求创建账户。
- 不包含广告、分析统计或遥测服务。
- 不上传文件内容、文件名、文件夹名、布局或使用记录。
- 不建立文件内容全文索引。
- 只在用户选择或执行明确文件操作时访问本地文件夹。

布局、偏好和可逆操作记录保存在用户 Mac 的 `Application Support/SpatialFolder` 目录。用户导出的诊断 JSON 不包含文件名、文件夹名或完整路径。

## 系统权限

访问桌面或其他受保护位置时，macOS 可能要求文件与文件夹权限。全局快捷键使用系统热键接口，不需要辅助功能或输入监控权限。

## 删除数据

卸载 App 不会删除用户的真实文件。若要同时移除指针空间保存的布局和操作记录，可在退出 App 后删除 `~/Library/Application Support/SpatialFolder`；执行前建议保留备份。
