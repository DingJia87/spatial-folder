# 空间文件夹 v4.2.0

4.2集中修复Finder标签在画布中的同步、颜色显示和重复写入问题。

## 主要变化

- Finder或其他App修改标签后，画布约一秒内同步，无须重启或重新选择文件夹。
- 文件夹图标本体按首个Finder颜色标签着色；普通文件保留原图标并显示标签点。
- 清除标签后再选新颜色，只保留新颜色，不会从旧右键菜单状态恢复旧标签。
- 顶部筛选和右键标签菜单显示红、橙、黄、绿、蓝、紫、灰原色圆点；选中颜色显示同色勾选圆点。
- 标签核对不读取图标、不保存布局，也不修改真实文件。

## 安装

- App：`Release/4.2.0/空间文件夹.app`
- ZIP：`Release/4.2.0/空间文件夹-v4.2.0.zip`
- 内部版本4.2.0，构建号4200，使用ad-hoc本地签名；尚未进行Developer ID公证。
