# 空间文件夹 v3.0.0

3.0 精简顶部工具栏，并修复锁定画布时系统桌面壁纸无法生效的问题。真实文件操作、画布布局格式和操作历史格式均不迁移。

## 用户可见变化

- 当前空间名称、选择文件夹和最近空间合并为一个菜单。
- 顶部常驻空间、搜索、标签筛选、刷新和“更多”；异常、恢复与待放置状态按需出现。
- 锁定、壁纸、外观、最近操作和布局维护收进分组菜单。
- 画布锁定后仍可更换自定义壁纸或选择“使用系统桌面壁纸”。
- 系统壁纸继续跟随 App 当前所在显示器。

## 安全与兼容

- 锁定仍会阻止图标移动、排列和其他布局写入。
- 只读会话、损坏布局、不可用文件夹或历史加载期间不会写入壁纸设置。
- 不修改真实文件，不迁移布局或事务格式，可直接继续使用 2.6 的空间数据。

## 验证

- 10 项标准 SwiftPM 测试。
- 68 项完整兼容性和真实文件事务回归。
- 严格 Debug/Release 构建、性能基线和隔离 GUI 壁纸切换检查。
- App 与 ZIP 的 ad-hoc 签名及解压复验。

## 安装位置

- `Release/3.0.0/空间文件夹.app`
- `Release/3.0.0/空间文件夹-v3.0.0.zip`

当前包使用 ad-hoc 本地签名，尚未使用 Apple Developer ID 公证。
