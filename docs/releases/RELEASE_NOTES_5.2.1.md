# 指针空间 v5.2.1 安全修复候选

5.2.1 不增加新功能，专注保护真实文件。

## 修复内容

- 重命名不再接受可能跳出当前空间的路径式名称。
- 复制、移动、替换和重命名会在真实文件改动前检查整批目标边界。
- 打包流程不再静默删除并重建同名产物，降低冻结版被误覆盖的风险。

## 资源影响

安全检查只在用户发起文件操作时执行；没有新增定时器、文件监听、索引、遥测或常驻缓存。单次批量校验随当次项目数线性增长，相对真实复制/移动成本很小。
