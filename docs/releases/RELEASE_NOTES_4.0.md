# 空间文件夹 v4.0.0

4.0 增加“一键收纳桌面”，让当前空间成为桌面临时文件的快速入口。

## 如何使用

- 在目标空间顶部点击托盘向下箭头按钮。
- 或使用快捷键 `⇧⌘D`。
- 文件与文件夹会真实移动到当前空间，并叠放在画布右侧中下部。

## 行为边界

- 文件夹内部结构不会改变。
- 同名项目自动保留两者。
- 整堆显示数量角标，拖走顶层项目后逐个露出。
- 收纳点被占用时整堆寻找附近空位，已有画布图标不会重新排列。
- 隐藏项目和常见未完成下载文件不会移动。
- 主画布放满后，新增项目进入待放置区。
- 整批收纳可从最近操作一次撤销。
