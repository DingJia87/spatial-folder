# 空间文件夹 v4.1.0

4.1 让空间画布从“需要找到并点击的 App”变成随时可以叫出、用完立即收回的工具。

## 使用

1. 默认按 `⌃⌥空格` 显示空间文件夹。
2. 主窗口已经在最前时，再按一次即可隐藏。
3. 在“更多 → 全局快捷键设置”中可录制新组合键、停用或恢复默认。
4. 菜单栏的网格图标始终提供相同入口。

若新组合键已被系统或其他 App 占用，设置不会生效，原快捷键继续保留。

Finder 或其他 App 修改标签后，画布会自动刷新，不再需要关闭 App 或重新选择文件夹。文件夹图标本体会按 Finder 标签着色；普通文件保留原图标并显示颜色点。
