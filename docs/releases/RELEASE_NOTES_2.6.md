# 空间文件夹 v2.6.0

2.6 增加 Finder 标签颜色筛选，并修复筛选状态下批量选择边界。文件系统、画布布局格式和操作历史格式均不迁移。

## 用户可见变化

- 顶部移除低频“新建文件夹”按钮；新建功能仍在画布右键“新建”菜单中。
- 搜索框旁新增标签菜单，可筛选红、橙、黄、绿、蓝、紫、灰和无标签项目。
- 多颜色按任一匹配，搜索和标签条件同时生效。
- 没有匹配项时显示明确提示并可一键清除；切换空间会清空临时筛选。
- 顶部筛选不再隐藏待放置区；待放置面板保持自己的搜索和批量选择。
- 自定义 Finder 标签名称仍按其真实颜色编号显示和筛选。

## 文件安全修复

2.5 中，搜索可以隐藏已选项目，但选择集合仍可能保留这些项目；随后从另一个已选图标打开批量菜单，隐藏文件也可能成为剪切、压缩、标签或废纸篓的目标。2.6 在筛选变化时移除隐藏选择，并让批量命令只从当前可见选择生成目标集合。

## 验证

- 10 项标准 SwiftPM 测试。
- 67 项完整兼容性和真实文件事务回归。
- 连续三次性能基线中，3,000 项扫描中位数为 0.137 秒。
- 严格 Debug/Release 构建和隔离 Bundle ID 的 GUI 冒烟检查通过。
