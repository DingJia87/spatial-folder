# 指针空间 v5.2.0

5.2 将常用文件夹变成主窗口顶部可见的空间快捷入口，减少在菜单中反复寻找文件夹的步骤。

## 新增

- 顶部按打开顺序保留最多 5 个空间，当前空间只改变高亮，不会跳到首位。
- 点击空间名称即可切换画布；长名称会截断，悬停可查看完整路径。
- 第 6 个新空间会先要求选择替换位置，确认前不切换，其他位置保持不变。
- 空间支持拖动排序，设置会跨重启保存；右键非当前空间可移出顶部。
- 入口右侧新增排序手柄，修复只有两个空间时从左向右拖动没有变化的问题。
- 每个空间独立保存最近 3 步布局撤销与重做，切换或重启后仍可继续。
- 未显示的固定空间和最近空间统一收纳在尾部“更多空间”菜单。

## 轻量原则

未激活空间只保存文件夹书签，不扫描目录、不监听变化，也不加载文件图标。切换时会先结束旧空间的扫描、监听、标签任务并清理图标缓存，然后只加载新的当前空间。

## 文件安全边界

空间切换只更改当前显示目标，不会复制、移动或修改真实文件。文件操作执行期间暂时禁止切换，避免操作上下文跨空间。
