# 指针空间 v5.1.0

5.1 把原来需要在 Finder 中辨认的布局 JSON，整理成 App 内可直接理解的“布局历史”。

## 新增

- 按时间和原因查看最多 12 份布局备份。
- 并排预览当前布局与备份布局。
- 恢复前显示将调整、不变、新增和已不存在的项目数量。
- 支持恢复任意备份和保存带备注的手动布局快照。
- 手动快照严格保存当前画布状态，不会混入磁盘旧布局或已经不在当前画布中的失效坐标。
- 保存快照时提供包含日期和时间的推荐名称；可在布局历史中删除不再需要的所选备份。

## 恢复边界

该功能恢复的是图标布局，不是文件。备份中的真实文件若已经删除，App 只提示并忽略对应布局记录；不会创建、复制或找回文件。备份后新增的文件保持当前位置。

默认保留当前壁纸和锁定状态；只有勾选“同时恢复当时的壁纸和锁定状态”时才恢复外观设置。
