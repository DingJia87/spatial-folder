# 指针空间 v5.0.0

空间文件夹正式更名为“指针空间”：用位置记住文件。

## 本次更新

- App、菜单栏、窗口、安装包和诊断文件使用新名称。
- 窗口隐藏、关闭或最小化时暂停 Finder 标签轮询，减少无意义的后台唤醒。
- 重新显示窗口时立即核对标签，不牺牲可见状态下的同步体验。
- GitHub 主页和文档按产品、用户指南、隐私、支持与开发档案重新组织。

## 升级兼容

Bundle ID、布局目录、最近空间、快捷键偏好和操作历史均保持不变。升级时请先退出并移除旧的“空间文件夹.app”，再安装“指针空间.app”；不要同时运行两个名称的 App。
