# 当前项目状态与任务交接

最后更新：2026-08-09

## 产品定位

指针空间是一款原生 macOS 空间文件画布，帮助用户依靠文件的稳定位置快速定位。真实文件夹是数据源，画布只保存布局元数据；不可违反的文件安全规则见根目录 `AGENTS.md`。

- 当前正式版本：`v5.2.0`，构建号 `5200`
- 发布分支：`codex/release-5.1`（连续包含 v5.1、v5.2 发布提交）
- 上一冻结版本：`v5.1.0`
- 5.2 正式产物：`Release/5.2.0/指针空间.app`、`Release/5.2.0/指针空间.zip`

- 稳定数据目录：`Application Support/SpatialFolder`

`Release/5.1.0/`与`Release/5.2.0/`均已冻结，后续开发不得覆盖。

## 5.2 范围

- 顶部按打开顺序保留最多 5 个稳定空间位置，点击只改变高亮，不自动换位。
- 第 6 个新空间必须明确选择替换槽位；确认前不切换，其他槽位位置不变。
- 支持拖动排序、移除非当前入口和跨重启恢复顺序；窄窗口放不下的入口进入更多菜单。
- 入口右侧使用独立拖动手柄；源空间占据目标位置，修复两个空间从左向右拖动无变化。
- 每个空间独立持久化最近 3 步布局撤销与重做，切换或重启后继续自己的历史。
- 只有当前空间扫描文件、加载图标并保持文件夹监听和标签核对。
- 切换空间复用既有单活动生命周期，文件操作进行中禁止切换。

## 不变边界

- 只显示所选真实文件夹的直接子项目。
- 画布拖动不移动真实文件。
- 删除必须进入 macOS 废纸篓。
- 新项目不得重排已有项目。
- 不增加索引、云同步、遥测或常驻自动整理。
