# 当前项目状态与任务交接

最后更新：2026-07-26

## 一、项目定位

空间文件夹是一款原生 macOS 应用。它把用户选定真实文件夹的第一级内容显示为稳定的桌面式画布，让依赖空间记忆的用户通过文件长期固定的位置组织工作。

文件系统是真实数据源，画布只保存显示和布局元数据。删除必须把真实文件移入废纸篓；拖动画布图标不能改变真实文件路径。完整不可违反规则见根目录 `AGENTS.md`。

## 三、当前能力

- 只展示所选真实文件夹的第一级文件和文件夹。
- 图标自由摆放、网格吸附、位置持久化、多选与框选。
- 文件由 macOS 默认应用打开，文件夹在 Finder 中打开。
- 支持真实新建、重命名、复制、标签、废纸篓及撤销/重做。
- 支持外部拖入、批量操作、待放置区和显示器切换。
- 支持窗口比例、系统外观、壁纸、恢复分析、增量操作日志及画布会话锁。
- 详细功能、安全边界和已知限制以根目录 `README.md` 为准。

## 六、新任务执行规则

开始新任务时按以下顺序：

1. 阅读 `AGENTS.md`、`README.md`、本文件和 `docs/README.md`。
2. 运行 `git status -sb`，确认当前分支和未提交内容。
3. 复述本次目标、影响范围和冻结基线，再开始修改。
4. 不覆盖当前可用安装包；开发版本使用新分支，并统一放入 `Release/<版本>/`，名称明确标记开发状态。
5. 修改后至少运行：

```zsh
./scripts/run_standard_tests.zsh
./scripts/run_self_tests.zsh
```

6. 用户验证开发版后再打包、冻结、提交和发布。
