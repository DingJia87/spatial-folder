# 当前项目状态与任务交接

最后更新：2026-08-11

## 产品定位

指针空间是一款原生 macOS 空间文件画布，帮助用户依靠文件的稳定位置快速定位。真实文件夹是数据源，画布只保存布局元数据；不可违反的文件安全规则见根目录 `AGENTS.md`。

## 5.3.0 正式试用范围

- 整合 5.2.1 的重命名/批量目标边界保护和 5.2.2 的全写入授权闭环。
- 重命名、复制/移动、压缩、废纸篓、新建、标签和撤销/重做在改动磁盘前预检当前空间边界。
- 文件修改与日志落盘之间的意外中断有明确的重启核对与回滚测试。
- 顶部空间标签拖动状态下沉到单枚标签，背景、描边和内容作为整体移动，减少闪烁。
- 不增加监听、轮询、索引、云同步、遥测或常驻缓存。

## 5.2.2 写入安全闭环范围

- 压缩、废纸篓、新建、标签、复制/移动以及撤销/重做统一携带当前空间授权上下文。
- 所有真实文件写入入口都在修改磁盘前完成整批边界预检。
- 撤销/重做保留“外部来源 ↔ 当前空间”导入语义，但禁止两端都与当前空间无关的记录。
- 废纸篓恢复路径只接受系统用户废纸篓、卷废纸篓或测试注入目录。
- 新增“文件修改与日志落盘之间中断”的故障注入回归，覆盖重启核对与可捕获失败回滚。
- 顶部标签的高频拖动状态下沉到单枚标签，内容、背景和描边合成后整体移动，避免整条工具栏重算与错帧闪烁。
- 本版不增加监听、轮询、索引、UI 或常驻缓存。

## 5.2.1 安全修复范围

- 危险重命名输入在进入冲突检查或真实文件操作前立即拒绝。
- 协调器在整批复制、移动和替换前校验目标边界；制作副本和重命名同时校验来源边界。
- 校验是用户发起操作时的 O(n) 短时计算，不新增监听、定时器、索引或常驻缓存。
- 打包脚本拒绝静默覆盖已有产物，且 5.2.1 候选名称与正式包分离。
- 不包含布局历史、压缩、多空间交互或 UI 功能改动。

## 5.2 范围

- 顶部按打开顺序保留最多 5 个稳定空间位置，点击只改变高亮，不自动换位。
- 第 6 个新空间必须明确选择替换槽位；确认前不切换，其他槽位位置不变。
- 支持拖动排序、移除非当前入口和跨重启恢复顺序；窄窗口放不下的入口进入更多菜单。
- 入口右侧使用独立拖动手柄；源空间占据目标位置，修复两个空间从左向右拖动无变化。
- 每个空间独立持久化最近 3 步布局撤销与重做，切换或重启后继续自己的历史。
- 只有当前空间扫描文件、加载图标并保持文件夹监听和标签核对。
- 切换空间复用既有单活动生命周期，文件操作进行中禁止切换。

## 不变边界

- 只显示所选真实文件夹的直接子项目。
- 画布拖动不移动真实文件。
- 删除必须进入 macOS 废纸篓。
- 新项目不得重排已有项目。
- 不增加索引、云同步、遥测或常驻自动整理。
