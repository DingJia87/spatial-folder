# 当前项目状态与任务交接

最后更新：2026-08-09

## 产品定位

指针空间是一款原生 macOS 空间文件画布，帮助用户依靠文件的稳定位置快速定位。真实文件夹是数据源，画布只保存布局元数据；不可违反的文件安全规则见根目录 `AGENTS.md`。

## 当前基线

- 当前正式版本：`v5.1.0`，构建号 `5100`
- 发布分支：`codex/release-5.1`
- 上一冻结版本：`v5.0.0`
- 正式产物：`Release/5.1.0/指针空间.app`、`Release/5.1.0/指针空间.zip`
- 稳定 Bundle ID：`com.dingjia.spatialfolder`
- 稳定数据目录：`Application Support/SpatialFolder`

`Release/5.0.0/`与`Release/5.1.0/`均为冻结包，后续开发不得覆盖。

## 5.1 范围

- App 内“布局历史”按时间预览和比较最多 12 份自动备份或手动快照。
- 恢复只调整位置、大小、待放置状态和基准画布，不恢复或改动真实文件。
- 已删除文件在恢复时明确提示并忽略；备份后新增文件保持当前位置。
- 保存快照提供推荐名称，支持删除所选备份。
- 导入、导出与显示备份位置统一收进“布局历史”的更多菜单。
- 顶部提供独立撤销、重做、刷新按钮及明确的动态悬停说明。

## 不变边界

- 只显示所选真实文件夹的直接子项目。
- 画布拖动不移动真实文件。
- 删除必须进入 macOS 废纸篓。
- 新项目不得重排已有项目。
- 不增加索引、云同步、遥测或常驻自动整理。
